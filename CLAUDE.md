# Island Traders

## Commits and pull requests

- Never add `Co-Authored-By` lines, "Generated with Claude Code" or claude.ai session links to commits or pull requests.
- When starting a new or empty repository, add `.claude/settings.json` with the attribution setting below in the first commit:

  ```json
  {
    "attribution": { "commit": "", "pr": "", "sessionUrl": false }
  }
  ```
